# Policies & Bonus Techs

**Policies** occupy one of **5 policy slots** (expandable to 9 via Hereditary Rule/Democracy/Socialism/
Technocracy). **Bonuses** are passive one-time modifiers with no slot. Percentage effects stack
**additively** (SCALING §2). All magnitudes **`[proposed]`**; eras thematically spread.

## Watch-points

1. **Legitimacy snowball is now acute.** The Theocracy line (**+25 / +100 / +400 legit per era**) +
   Organized Religion (gold = legit) + the legit-leverage buildings (Elysium, Monastery, Hagia Sophia
   ×2) is a strong loop. **Deepfaked Reality +400/era** especially — decide if the line should be
   smaller or diminishing.
2. **Democracy changed roles.** In v2 it's a **policy-slot unlocker** (per your dump), NOT the old
   legit-loss doubler — so **Freedom of Religion** is now the (sole) legit-loss doubler. Updated here.
3. **Damage stacking is additive but deep:** category doctrine (+50%) + Steel-line (+15…60%) + command
   auras (+50/100%) + Caste (+25%) + Adaptive (+120%) can pile very high on one unit. Intended, but the
   ceiling is worth a look once combat is tuned.
4. **Invented extras** (Golden Age / Manifest Destiny / Transhumanism, + the "Optics = naval" and
   "Liminite" name-split) — confirm or cut.
